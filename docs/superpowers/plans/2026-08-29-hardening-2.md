# Hardening Phase 2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hoàn thiện đường chạy production duy nhất, loại fallback ảnh rủi ro, chuẩn hóa publish outcome và dùng CI làm gate cho `main`.

**Architecture:** Giữ `hardening_runner.py` làm entry point duy nhất. Dọn source legacy để không còn bypass TLS; `runner.py` chỉ dùng Pexels hoặc text-only; `fun`/`recipe` trả lỗi rõ khi primary publish không có Facebook ID; CI chịu trách nhiệm test trước merge còn workflow cron chỉ chạy bot.

**Tech Stack:** Python 3.11, unittest, GitHub Actions, Turso/libSQL, Facebook Graph API, Gemini, Pexels.

**Spec:** `docs/superpowers/specs/2026-08-29-hardening-2-design.md`

## Global Constraints

- Không đổi cron, secret names, Facebook Graph API version hoặc số job/ngày.
- Không thêm hạ tầng mới.
- Không dùng Bing fallback.
- CI branch phải xanh trước fast-forward `main`.
